# Wizardry Tutoring demo

Standalone static presentation site. Only Get Started links from the homepage; it opens a five-question assessment with scoring, answer review and a sample study PDF. Navigation and account labels are presentation-only. No accounts, payments, data collection or backend.

Serve this directory with any static web server. For Vercel, import this repository as a separate project, choose Other, leave the build command empty, and use the repository root as the output directory.

Clinical content is an educational demonstration, not a validated competency assessment. References appear in the result and PDF.
